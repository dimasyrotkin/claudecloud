# ZIP α — style bible ("Riso Idol")

**One line:** a K-pop debut teaser printed on a risograph. Cream paper, three translucent inks, die-cut stickers, and type that literally compresses.

## Why this look
- The 2026 feed is full of glossy AI video. Tactile print (grain, misregistration, halftone) reads as *made by hand*, which stands out and signals craft.
- K-pop teaches attention: a cut or a word on every beat, symmetric hero frames, one repeated "point move", colour-block set changes per bar, an idol mascot.
- Compression is the product, so the design system itself compresses: the display face **Anybody** has a 50–150 % width axis. Bloat = wide. Zipped = condensed. Still perfectly legible = *lossless*.

## Inks (multiply like real riso)
| token | hex | role |
|---|---|---|
| paper | `#F4EDE0` | ground, always textured |
| ink | `#1B1A2B` | type, outlines |
| blue | `#2748E8` | Zip, "with Zip", good |
| pink | `#FF4FB0` | alarm, accent words, competitors |
| yellow | `#FFD84D` | tokens, money, highlights |
| overprints | blue×pink `#27169F`, pink×yellow `#FF4535`, yellow×blue `#274046` | shading and shadows only |
| green (Y2K section only) | `#00A95C` | CRT phosphor |

## Type
- **Anybody** 800–900, width 50–150: every headline. Width is animated to show bloat vs zip.
- **Instrument Serif Italic**: one accent word per line ("in half", "only", "improves"). Elegant contrast, very 2025 SF.
- **JetBrains Mono**: terminals, labels, data, small print that rewards a second watch.

## Motifs (only these five)
1. **The zipper**: Zip's mouth, the logo, and the signature transition (a zipper closes across the frame).
2. **Width axis**: text inflates and zips.
3. **Overprint + misregistration**: pink plate jumps a few px on snares.
4. **Paper cut**: scissors, ransom-note scraps, stamps, torn edges, hard drop shadows.
5. **Halftone**: shading, glows and dissolves.

## Modes
- **POSTER**: type only, full-frame, huge (hooks, punchlines).
- **STAGE**: characters on paper-diorama sets. Type left, character right.
- **DATA**: terminals and charts as printed paper cards (mono type, grids).

## Characters
- **Zip**: a die-cut blue squircle idol with a *zipper for a mouth*, sparkle eyes, halftone blush, an ahoge curl. Point move: pinch the zipper and pull it shut ("zip it"). Used 4×: debut, zipping Bloat, the drop, the end card.
- **Bloat**: an overinflated paper blob stuffed with scribbled tokens. Wide, sweaty, drooling tokens. Zipped, it becomes a tiny tidy cube.
- **Tokens**: yellow hex chips, sometimes with dot eyes.
- **Engineer, Unicorn, the 2000 lab team**: flat paper figures, ink outline.

## Rules
- Every frame is designed, frame 0 included. Nothing holds still longer than about 1.2 s.
- Cuts land on beats (120 BPM, beat = 0.5 s) and sit at least 0.36 s apart. Big set changes land on downbeats.
- Text never covers a face. In STAGE shots, type goes left and the character goes right.
- All randomness is seeded. Lines "boil" at 12 fps like stop-motion prints.
